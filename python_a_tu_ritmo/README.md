# Python a tu ritmo

Aplicación web para practicar fundamentos de Python con lecciones, preguntas y una sopa de letras.

## Ejecutar

Para usar todas las funciones, inicia un servidor local en la carpeta del proyecto con `python -m http.server 8000` y abre `http://localhost:8000`. También puedes publicarlo en GitHub Pages. El progreso se guarda en el navegador y dispositivo que utilizas.

## Contenido disponible

La ruta incluye lecciones desde fundamentos hasta una introducción a temas avanzados, con ejemplos y preguntas, además de una sopa de letras. El laboratorio usa Pyodide para ejecutar Python en el navegador: requiere conexión a internet para cargarlo y no admite todas las librerías ni programas interactivos con `input()`. El contenido es una base ampliable, no una cobertura exhaustiva del ecosistema de Python.

## Publicación en GitHub Pages

Sube `index.html` y `README.md` a la raíz de tu repositorio. En GitHub, entra en Settings > Pages, selecciona la rama `main` y la carpeta raíz (`/root`), guarda y espera el enlace de publicación. Si el repositorio es privado, la disponibilidad de Pages depende del plan de GitHub.

## Ejercicios por tema

La sección **Ejercicios por tema** ofrece 102 variantes guiadas para cada una de las 40 lecciones (4.080 en total). Las primeras 101 variantes combinan cuatro tipos de reto por tema con situaciones distintas; la última plantea un reto adicional. Son variantes de práctica, no 4.040 problemas diseñados individualmente ni preguntas de selección múltiple. Puedes marcarlas manualmente; el progreso se guarda en el navegador y no se verifica la respuesta de forma automática. Los ejercicios de terminal, paquetes, archivos o `input()` pueden requerir Python instalado en el computador.

## Preguntas rápidas

Hay 80 preguntas de selección múltiple: dos por cada una de las 40 lecciones. Es necesario responder correctamente la pregunta actual antes de usar el botón «Siguiente pregunta»; si la respuesta es incorrecta, se ofrece una pista y se permite volver a intentar. El acceso a lecciones, otras secciones y ejercicios abiertos sigue disponible para repasar. Los ejercicios abiertos se marcan manualmente y no tienen corrección automática.
