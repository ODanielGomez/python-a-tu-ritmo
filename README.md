# Python a tu ritmo

Una aplicación web estática en español para aprender Python mediante lecciones, preguntas, pistas y práctica. Compatible con GitHub Pages.

## Uso local

Desde esta carpeta ejecuta `python -m http.server 8000` y abre `http://localhost:8000`. También puedes publicar estos archivos en GitHub Pages. Para ejecutar código Python se necesita internet porque el intérprete Pyodide se carga desde una red de distribución.

## Ruta y práctica

La ruta contiene 40 etapas. Las seis primeras tienen diez retos interactivos por etapa. Las demás tienen cuatro retos: dos de escritura de código y dos de selección múltiple. Las dos preguntas de cada prueba final reutilizan las preguntas de selección múltiple de la práctica y requieren ampliación para una evaluación independiente.

El verificador de código compara la salida, por lo que una respuesta puede aprobar imprimiendo la salida sin usar el concepto solicitado. No sustituye una revisión del código ni una evaluación de comprensión. La mayoría de los temas avanzados son introducciones breves y requieren más profundidad, ejercicios, proyectos y revisión pedagógica antes de considerarse un curso completo.

Las secciones de ejercicios abiertos contienen variantes generadas; se marcan manualmente y no son problemas únicos ni se califican automáticamente. En ejercicios de entrada se usan valores simulados. Algunos ejemplos sobre paquetes, redes y archivos son ilustrativos porque la ejecución en el navegador tiene limitaciones.

## Progreso y privacidad

El avance de la ruta se guarda en el almacenamiento local del navegador, sin cuentas, servidor ni sincronización. Borrar los datos del navegador puede eliminar el progreso. El progreso de retos abiertos de versiones anteriores se conserva en el almacenamiento, pero no cuenta como reto verificado de las etapas 7 a 40; esas etapas requieren resolver los retos nuevos. El botón de reiniciar elimina el progreso local tras confirmarlo.

## Evaluación de la primera etapa y simulacro

La primera etapa incluye 14 retos, de los cuales 10 son de selección múltiple, y una evaluación nueva de 15 preguntas. Se aprueba con al menos 12 aciertos; cuando se termina con menos, se reinicia el progreso de toda la ruta, como se indica antes de comenzar. Se muestra una revisión de las respuestas. Los intentos se guardan localmente mientras se responde.

La sección Simulacro de entrevista toma hasta diez preguntas de los temas completados del banco existente y muestra la revisión al final. No modifica el avance de la ruta; utiliza preguntas existentes, no un banco nuevo ni entrevistas adaptativas.

Limitación esencial: las etapas 2–40 todavía mantienen la evaluación anterior de dos preguntas y no aplican la regla de reinicio por nota. Las etapas 2–6 no tienen todas diez preguntas de opción múltiple separadas de los ejercicios, y las etapas 7–40 mantienen cuatro retos. Falta diseñar y revisar las evaluaciones de 15 preguntas, preguntas de práctica y proyectos para esas etapas. No es todavía el curso completo solicitado.

## Repaso acumulativo (en construcción)

Antes de la evaluación de los temas posteriores se muestra un repaso de hasta cinco preguntas, tomadas de temas anteriores completados. El repaso ofrece explicaciones y no afecta la nota. Usa por ahora las preguntas existentes del banco, por lo que aún necesita un banco más amplio e independiente.
